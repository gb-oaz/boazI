# **Boaz - Plataforma Educacional Interativa**

> **"Na força do conhecimento, a sabedoria floresce"**

A **Boaz** é uma plataforma educacional completa que combina duas soluções poderosas: **BoazHub** (central de administração) e **BoazQuest** (aplicativo de quiz interativo). Inspirada em plataformas como Kahoot e Quizizz, oferece uma experiência gamificada que torna o aprendizado dinâmico e envolvente.

## **🌐 Nossas Aplicações**


### **⚙️ BoazHub** - *Central de comando educacional*
- **URL:** [`https://hub.boaz.app`](https://hub.boaz.app)
- **Função:** Painel administrativo para educadores
- **Características:**
  - Criação e gestão de quizzes
  - Análise de desempenho e relatórios
  - Gestão de usuários e grupos
  - Configurações avançadas da plataforma

### **🎯 BoazQuest** - *Seu desafio de conhecimento!*
- **URL:** [`https://quest.boaz.app`](https://quest.boaz.app)
- **Função:** Aplicativo principal de quiz interativo
- **Características:**
  - Quizzes dinâmicos em tempo real
  - Experiência gamificada para estudantes
  - Interface intuitiva e responsiva
  - Sistema de ranking e recompensas

## **🚀 O que é a Plataforma Boaz?**
- **Ecossistema educacional completo** com duas aplicações integradas
- **Gamificação educacional** que transforma aprendizado em diversão
- **Tecnologia de ponta** com arquitetura de microsserviços
- **Experiência multiplataforma** acessível em qualquer dispositivo

## **Para que serve?**
- **Para escolas:**
  - Oferecer ferramenta de ponta para professores.
  - Oferecer qualidade de conteúdo avaliativo para estudantes.
- **Para educadores:**
  - Criar quizzes para avaliar e engajar alunos.
  - Estimular o aprendizado de forma lúdica.
- **Para estudantes:**
  - Testar conhecimentos de maneira divertida.
  - Reforçar conteúdos de estudo com desafios personalizados.
- **Para empresas:**
  - Aplicar treinamentos interativos.
  - Realizar dinâmicas de equipe com quizzes personalizados.

### **🎯 Modelos de Negócio**

#### **👤 B2C (Business to Consumer)**
- **Público:** Professores individuais
- **Vantagem:** Ciclo de venda rápido, sem burocracia
- **Ticket:** R$ 15/mês ou R$ 160/ano por professor
- **Estratégia:** Marketing digital, conteúdo educacional gratuito

#### **🏢 B2B (Business to Business)**
- **Público:** Escolas e instituições de ensino
- **Vantagem:** Ticket médio maior, escala institucional
- **Proposta:** Licença institucional por escola
- **Exemplo:** R$ 300/mês para escolas com até 25 professores

## **🎮 Como funciona?**

### **Para Educadores (BoazHub):**
1. **Acesse** [`hub.boaz.app`](https://hub.boaz.app) e faça login
2. **Crie** quizzes personalizados com diferentes tipos de questões
3. **Configure** salas virtuais e códigos de acesso
4. **Monitore** o progresso em tempo real
5. **Analise** relatórios detalhados de desempenho

### **Para Estudantes (BoazQuest):**
1. **Acesse** [`quest.boaz.app`](https://quest.boaz.app)
2. **Insira** o código da sala fornecido pelo educador
3. **Participe** do quiz em tempo real ou modo assíncrono
4. **Compete** com outros participantes no ranking
5. **Acompanhe** seu progresso e conquistas

## **🏗️ Arquitetura da Solução**

A plataforma Boaz utiliza uma arquitetura moderna de microsserviços:

### **🔧 Componentes Principais:**
- **Frontend Microfrontend:** Arquitetura modular com Vue.js
- **Backend Microsserviços:** Spring Boot com Clean Architecture
- **Core Shared:** Biblioteca compartilhada entre serviços
- **Database:** MongoDB para persistência de dados
- **Container:** Docker e Kubernetes para orquestração

## **🚀 Quick Start**

### **📋 Pré-requisitos**
- Java 21+ ☕
- Node.js 18+ & Yarn 📦
- Docker & Docker Compose 🐳
- MongoDB 🍃

### **⚡ Executar a Aplicação**

```bash
# Clone o repositório
git clone https://github.com/GustavoBoaz/pi.git
cd pi

# Executar com Docker Compose (Recomendado)
docker-compose up -d

# Ou executar separadamente:
# Backend
cd backend && docker-compose up -d

# Frontend
cd frontend && yarn install && yarn dev
```

### **🌐 Acessar as Aplicações**
- **BoazHub:** http://localhost:3000 (Admin Panel)
- **BoazQuest:** http://localhost:3001 (Quiz App)
- **API Docs:** http://localhost:8000/docs/swagger-ui.html

## **🔧 Guia de Desenvolvimento**

<details>
  <summary>🌐 Frontend (BoazQuest & BoazHub)</summary>

### **📦 Instalação e Configuração**

```bash
# Navegar para o diretório frontend
cd frontend

# Instalar dependências
yarn install

# Executar em modo desenvolvimento
yarn dev

# Build para produção
yarn build

# Executar build de produção
yarn start
```

### **🏗️ Estrutura do Frontend**
```
frontend/
├── shell_core/          # BoazQuest - App principal de quiz
├── remote_common/       # Componentes compartilhados
└── package.json         # Configuração do workspace
```

### **🚀 URLs de Desenvolvimento**
- **BoazHub:** http://localhost:3000
- **BoazQuest:** http://localhost:3001

</details>

<details>
  <summary>☕ Backend (Microservices)</summary>

### **🔧 Configuração do Backend**

```bash
# Navegar para o diretório backend
cd backend

# Compilar todos os microsserviços
mvn clean compile

# Executar testes
mvn test

# Build completo
mvn clean package

# Executar com Docker
docker-compose up -d
```

### **🏗️ Estrutura dos Microsserviços**
```
backend/
├── core/               # Biblioteca compartilhada
├── ms_auth/           # Serviço de autenticação
├── ms_quiz/           # Serviço de quiz
├── ms_live/           # Serviço de transmissão ao vivo
├── ms_user/           # Serviço de usuários
└── ms_mono/           # Gateway/Monolito (desenvolvimento)
```

### **🌐 Endpoints Principais**
- **API Gateway:** http://localhost:8000
- **Swagger UI:** http://localhost:8000/docs/swagger-ui.html
- **MongoDB:** localhost:27017

</details>

<details>
  <summary>🐳 Docker & Deploy</summary>

### **🚀 Deploy com Docker**

```bash
# Build e execução completa
docker-compose up --build -d

# Visualizar logs
docker-compose logs -f

# Parar serviços
docker-compose down

# Reset completo (cuidado: remove dados)
docker-compose down -v && docker-compose up --build -d
```

### **📊 Monitoramento**
```bash
# Status dos containers
docker ps

# Logs específicos
docker logs [container-name]

# Recursos utilizados
docker stats
```
